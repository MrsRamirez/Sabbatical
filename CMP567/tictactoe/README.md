# Tic-Tac-Toe Celebration Edition

An enhanced browser-based Tic-Tac-Toe game created for CMP 567: Programming Methods I for Educators.

The human player is **X** and the computer is **O**. The computer selects a random available square after a one-second delay. The project includes a responsive interface, clear turn feedback, an animated end-of-game billboard, and confetti when the player wins.

## Features

- 3 × 3 CSS Grid game board
- Human and computer turns
- Random legal computer moves
- Human win, computer win, and draw detection
- New-game reset
- Responsive layout
- Keyboard focus styles and live status text
- Winner billboard and lightweight confetti animation
- Reduced-motion support

## Run locally

Open `index.html` in a modern web browser. No installation or external libraries are required.

## Files

- `index.html` — page structure
- `tictactoe.css` — layout, responsive styling, and animations
- `tictactoe.js` — game logic, status handling, billboard, and confetti
